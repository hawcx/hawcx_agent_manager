Hawcx Agent Manager

The desktop app that enrolls an employee's machine and the AI agents running on it with your Hawcx deployment. IT installs it through Intune or Jamf; your deployment runbook supplies the configuration.

Deploy

Install by hand for a test machine, or silently through your MDM for a fleet. Pick your platform.

Requires
macOS on Apple silicon or Intel. One universal build covers both.
Package
HawcxManager-<version>-macos-universal.pkg, signed with a Developer ID and notarized by Apple.
Installs
/Applications/Hawcx Manager.app, a system service, and a local service account named _hawcxauth. Administrator rights are required.
Config file
/etc/hawcx/manager.env

Install on one machine

Double-click the package, or from Terminal:

sudo installer -pkg HawcxManager-<version>-macos-universal.pkg -target /

Deploy with Jamf

Upload the package as-is and scope it with a policy that also places manager.env at the path above. The app reads that file at startup; without it, it has nothing to connect to.

Remove

Dragging the app to the Trash does not uninstall it and leaves the service in place. Use the uninstaller, which stays on the machine outside the app bundle:

sudo /opt/hawcx/bin/hawcx-uninstall.sh --dry-run   # show the plan, change nothing
sudo /opt/hawcx/bin/hawcx-uninstall.sh             # remove, keep the enrolled identity
sudo /opt/hawcx/bin/hawcx-uninstall.sh --purge     # remove and destroy the enrolled identity

The installer also offers a "Wipe clean first" choice on its Customize pane for re-enrolling a machine from scratch. It is off by default.

Requires
Windows 11, 64-bit. The WebView2 runtime that ships with Windows 11.
Packages
HawcxManager-<version>-windows-x64.msi for managed deployment. HawcxManager-<version>-windows-x64-setup.exe for interactive installs.
Installs
Per machine, for all users. Administrator rights are required.
Config file
C:\ProgramData\Hawcx\manager.env
Windows installers are not code-signed yet. SmartScreen shows a warning on interactive installs, and some managed fleets block unsigned installers. Deploy the MSI through your MDM from this page's URLs rather than by forwarding the file.

Install silently

msiexec /i HawcxManager-<version>-windows-x64.msi /qn /norestart

The interactive installer also accepts /S for a silent install.

Deploy with Intune

Add the MSI as a line-of-business app, assign it as required, and use a separate configuration policy or script to place manager.env at the path above before the app first runs. An app launched from the Start menu inherits no shell environment, so the file is the only way configuration reaches it.

Remove

Uninstall from Settings, Apps, or silently:

msiexec /x HawcxManager-<version>-windows-x64.msi /qn /norestart
Requires
x86_64. Debian or Ubuntu for the .deb; any distribution for the AppImage.
Config file
/etc/hawcx/manager.env
Linux builds are published for evaluation. Talk to Hawcx before rolling them out to a fleet.

Install

sudo apt install ./HawcxManager-<version>-linux-amd64.deb

Or make the AppImage executable and run it directly:

chmod +x HawcxManager-<version>-linux-x86_64.AppImage
./HawcxManager-<version>-linux-x86_64.AppImage

Remove

sudo apt remove hawcx-manager

Verify what you downloaded

Check the package before it goes into your MDM.

macOS

Both commands should name a Developer ID Installer certificate belonging to Hawcx and report the package as notarized.

pkgutil --check-signature HawcxManager-<version>-macos-universal.pkg
spctl --assess --type install -vv HawcxManager-<version>-macos-universal.pkg

Windows and Linux

These builds carry no signature yet. Download them only from this page or the releases list on GitHub, over HTTPS, and keep the URL you used in your deployment record so the source is auditable.

Stable URLs for scripts

The latest release, by file name, and a pinned version:

https://github.com/hawcx/hawcx_agent_manager/releases/latest/download/<file>
https://github.com/hawcx/hawcx_agent_manager/releases/download/v<version>/<file>

Configure

The installer carries no tenant settings. One plain-text file supplies them.

Your Hawcx deployment runbook produces manager.env from a template with the values that only exist once your environment is set up: the identity provider's authorize and token endpoints, the app registration's client ID, and the addresses of the services in your deployment. Your MDM places the file next to the app.

macOS and Linux
/etc/hawcx/manager.env, owned by root, readable by everyone.
Windows
C:\ProgramData\Hawcx\manager.env
Contains
Endpoints and identifiers only. The app is a public OAuth client and needs no secret, so nothing in the file is one. Keys the app does not recognize are ignored, so copy names exactly from the template.
When it is read
At startup. Update the file and relaunch the app to apply a change.
